## How to import examples

The example flows can either be imported via the clipboard or by importing directly in the Node-RED editor via the dialog **Import -> Import Nodes -> Examples -> node-red-contrib-ctrlx-automation**.

![examples-import-nodes.png](./images/examples-import-nodes.png)

**Keep in mind, that you need to insert valid credentials (username and password)** for your device and adjust your hostname inside of the communication nodes.
When importing several examples after each other a message `Some of the nodes you are importing already exist in your workspace.` appears. Please choose `View nodes...` and click on `Import selected`. Otherwise you could overwrite existing settings nodes.

### Get web token from authentication server

The following example shows how to get a web token from ctrlX OSs authentication server. The username and password has to be adapted in the `make header` function. This can be used to access ctrlX OS REST API.
In standard setting, the token get invalid after 8h and needs to be renewed. This can be done by e.g. adding an interval to the inject node, that is smaller than the tokens expiration time. 
Beware that each login generates a new valid token. Use logout to clear this token, otherwise they will pile up.
